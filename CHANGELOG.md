# Changelog

## v0.1 - 2026-10-18

Initial source release.

- Native macOS launcher with fuzzy app search and keyboard navigation.
- Match-quality ranking with persistent launch history to break ties.
- Background operation for fast reopening, with toggle, hide, and quit commands.
- Configurable colors, fonts, spacing, and screen position.
- Query editing with Ctrl+U and Ctrl+W.
- Homebrew source installation and standalone build/install scripts.
- Unit tests for configuration, search, history, instance locking, and launcher scripts.

Requires macOS 12 or later and Xcode Command Line Tools. This release contains source code, not a signed or notarized app binary.
